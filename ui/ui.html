Head and print adjustments

Standoff moves the head back from the shoulder; tip-stopped keys need some so the head clears the lock face. Extra cut depth deepens every cut to compensate for a printer that runs fat.

Automatic puts down the face that supports the teeth best. Some keyways leave the teeth slightly above that face; gaps up to the limit are filled so the teeth start on the first layer.

Open a .keycopy file to start

Every Key Copier format is supported, including double-sided car keys and tip-stopped keys. You can also pick a format above and type a bitting.

Printing

Print flat at 100% infill with 0.1–0.12 mm layers. PETG or a tough PLA holds up best. If the key binds in the keyway, raise the clearance before touching anything else.

What the STL contains

One closed, manifold solid in millimetres, already lying flat on the bed. The 2D DXF outline is the side profile for CAD or laser work.

Limits

Flipper measurements are only as precise as your alignment on its screen. A printed key is for occasional use; turn it gently, and have a locksmith cut a metal copy for daily use.
